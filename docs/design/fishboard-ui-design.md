# Fishboard UI 設計與實作規格

更新日期：2026-10-13（香港時間）

本文件記錄已確認的 OpenDesign 視覺方向，以及實作時新增的手機導覽要求，供後續設計、開發與驗收使用。正式網站的資料、登入、相片、地圖及裝備儲存流程沿用原有實作；OpenDesign 的示範資料與模擬帳戶不移入正式網站。

## 設計方向

- 品牌：Fishboard／釣魚日和。
- 主流、簡潔、專業，以白色和海洋藍為主，使用靜態淡藍背景與像素魚個性。
- 保留已獲確認的桌面版資訊層級及卡片配置，不以大型行銷首頁取代個人釣魚日誌。
- 原有 Three.js 釣組、水族箱、設定及紀錄操作必須保留，視覺整理不代表刪減功能。
- 頁面使用繁體中文；使用者輸入的魚名、地點及裝備型號保留原值。

## 頁面與導覽

| 入口 | 路徑 | 內容 |
| --- | --- | --- |
| 總覽 | `/` | 漁獲統計、水族箱、最近一筆漁獲、可搜尋及篩選的紀錄 |
| 魚種圖鑑 | `/collection` | 收藏魚種、釣獲次數、最長紀錄；點選進入魚種詳情 |
| 釣獲地點 | `/map` | 原有互動地圖、地點篩選與漁獲列表 |
| 設定 | `/settings` | 釣魚證、Three.js loadout、主題、備份與帳戶 |
| 魚種詳情 | `/species/[id]` | 魚種資料、統計及釣獲歷史 |
| 漁獲詳情 | `/catches/[id]` | 原相、尺寸、時間、地點、裝備快照、備註、編輯與刪除 |

不設獨立 loadout 導覽項目。裝備配置只放在設定頁的 `#loadout` 區域。舊 `/gear` 路徑保留重新導向至 `/settings#loadout`，供既有連結使用。

登入前保留 Google 登入頁。正式私人資料介面仍以登入狀態作邊界，不因設計預覽加入登入繞過功能。

## 桌面版

- 左側固定高度側欄，標準寬度 238px；中等桌面寬度可收為 200px。
- 側欄包含品牌、四個主要入口，以及簡短品牌文字。
- 頂部列顯示目前位置、主題切換及「新增漁獲」。
- 主內容維持最大 1400px，使用實用留白。
- 總覽先顯示三張統計卡：漁獲紀錄、已收藏魚種、最長紀錄；未記錄的尺寸顯示破折號。
- 下一列左側為水族箱，右側為最近一筆漁獲；中等寬度可轉為上下排列。
- 下方紀錄以清楚列表顯示魚種、日期／時間、地點及長度。支援搜尋魚種／地點，以及原有魚種、地點、年份篩選。

## 手機版與底部導覽

760px 以下使用手機版，390px 為主要驗收尺寸，並檢查更窄畫面。

### 分離式配置

```text
畫面左下                         畫面右下
[ 獨立 ＋ ]       留白             [ 總覽 · 圖鑑 · 地圖 · 設定 ]
```

- 新增按鈕獨立放左下，與右側導覽沒有共同背景、框線或連接部件。
- 新增按鈕標準為 56 × 56px，藍色、柔和陰影、圓角 20px；極窄畫面可收為 52px。
- 右側四個項目集中在緊湊玻璃膠囊內，以 icon 為主；保留可存取名稱及目前頁面標示。
- 手機導覽不含 loadout，設定入口必須保留。
- 底部位置為 `max(12px, env(safe-area-inset-bottom))`。正文保留底部空間，儲存裝備提示放在導覽上方。
- 選中背景使用 Framer Motion 的共享位置動畫與彈簧過渡；icon 有輕微選中位移。

### 捲動與新增按鈕動畫

- 向下連續捲動約 12px 後，新增按鈕向左移出畫面並淡出，伴隨很輕微旋轉；右方導覽保留。
- 向上連續捲動約 8px 後，新增按鈕回到左下。
- 接近頁面頂部（24px 內）一定顯示按鈕。
- 短距離方向抖動不應令按鈕不停閃現。
- Safari 頂部／底部回彈以實際可捲動範圍裁切，避免誤判方向。
- 切換頁面重新顯示新增按鈕；開啟新增漁獲視窗時保持可用狀態。
- 收起時移除按鈕的指標操作與 Tab 順序。
- `prefers-reduced-motion` 停用彈簧移動過渡，但保留清楚的顯示／隱藏狀態。

## 靜態背景（最新調整）

水波相關背景已按要求移除。頁面使用 `--fl-bg` 靜態淡藍／深藍底色，不建立背景 WebGL canvas，也不提供水波開關。水族箱的游魚及設定頁的 Three.js 釣組保留。

## 篩選與漁獲詳情（最新調整）

- 首頁紀錄標題旁顯示結果數量；搜尋和魚種／地點／年份篩選集中在獨立工具列。
- 篩選欄位保留明確標籤與「全部」選項，提供「清除篩選」；手機搜尋獨佔一列，三個欄位緊湊排列。
- 漁獲詳情以藍色主要按鈕「編輯漁獲」及紅色描邊次要按鈕「刪除紀錄」區分操作；刪除仍須確認。
- 魚種圖鑑使用獨立文字入口；手機操作按鈕並排且維持可點擊尺寸。
- 地圖與漁獲列表之間不再顯示地方篩選列表。進入頁面先顯示全部漁獲，點選 marker 才篩選該標記的漁獲。
- Marker 按地點名稱與座標分組；同名但不同座標不混合篩選。選中 marker 有明顯視覺狀態，列表上方提供「顯示全部」重設。

## 水族箱與裝備

### 水族箱

沿用原有游魚邏輯及像素魚素材。每個已釣獲魚種只出現一尾；保留選取資訊、暫停／繼續、減少動態與頁面隱藏處理。新版將水族箱放在總覽卡片內，不刪除原有互動。

### Three.js loadout

設定頁內繼續使用 `/models/fishing-rig.glb`、GLTFLoader、RoomEnvironment 及原有部件標記。

- 五個配件：釣竿、魚輪、主線、前導線、擬餌／魚餌。
- 桌面為斜向釣組，手機為直向構圖；保留與配件對應的引線。
- Hover、鍵盤 focus 或選取會高亮相應配件，其他部件降低透明度。
- 配件可獨立編輯，裝備名稱及已裝備數目保留。
- 只有尚未儲存的改動才顯示儲存提示；還原原值後提示消失。
- 新漁獲使用原有裝備快照流程；後續修改裝備不改寫舊漁獲。
- 不用靜態圖片或普通表格取代真實 3D 釣組。

## 驗收與證據邊界

- 單元測試覆蓋捲動門檻、方向切換及回彈行為；既有資料、裝備、儲存與安全測試仍須通過。
- 完成 TypeScript、lint 及正式 Next.js 建置。
- 本機使用原始 UI 元件及示範資料檢視桌面、390px 手機、設定、3D 模型、配件修改／還原、主題及新增表單。
- 畫面驗證用的示範資料與登入／路由適配器放在 repo 外的臨時預覽，不包含於正式產品或提交。
- 上述檢查不等同真實帳戶／線上服務驗收，也不等同實體 iPhone Safari、長時間 3D 效能或部署完成。
- 後續部署後仍需以真實裝置檢查安全區、捲動動畫、鍵盤／表單、3D 效能及私人資料完整流程。

地圖 marker 精確位置篩選新增測試於 `tests/catch-map.test.mjs`；分組 key 由 `lib/fish-log.ts` 的 `catchMarkerKey` 提供。
