## 來源與擷取

- 使用目前 `components/fishlog/`、正式 CSS、Geist 字體與 `/models/fishing-rig.glb`。
- 只使用 `data/species.ts`、`data/catches.ts` 的示範資料，以及示範裝備與「釣魚日誌會員」名稱；沒有私人帳戶或真實漁獲。
- 在 repo 外的臨時本機 fixture 替換 provider 與框架路由適配器，以便在背景擷取；登入繞過或測試帳戶沒有加入正式網站。
- 使用背景瀏覽器，等待海岸圖片與模型載入。桌面主頁及設定採完整頁面截圖，手機採 viewport 截圖。
- 手機列表從「瀏覽紀錄」跳轉；等待向左收起動畫完成才擷取。
- 截圖為實際渲染的 JPEG，未改圖、拼接或重新生成 UI。

更新時先核對主頁終點、導覽新增入口、手機地點文字與 3D 模型，重新擷取並檢查圖片；同步維護根目錄 `README.md` 的相對連結與本表尺寸。不要直接公開私人帳戶畫面。
